Cardinalidades y Relaciones

PACIENTE → CITA 1 : N
Un paciente puede tener muchas citas; cada cita pertenece a un solo paciente.
MÉDICO → CITA 1 : N
Un médico puede atender muchas citas; cada cita es atendida por un solo médico.
CITA → DIAGNÓSTICO 1 : 1
Cada cita genera máximo un diagnóstico. Dependencia existencial.
ESPECIALIDAD → MÉDICO 1 : N
Una especialidad puede asignarse a varios médicos; cada médico tiene una sola.
DEPARTAMENTO → MÉDICO 1 : N
Un departamento puede tener varios médicos; cada médico pertenece a uno.
